# 🪟 Sliding Window Algorithms

This repository contains solutions to important **Sliding Window problems** frequently asked in coding interviews (FAANG level).

---

## 🚀 What is Sliding Window?

Sliding Window is an optimization technique used to reduce time complexity from **O(n²) → O(n)** by maintaining a window (subarray/substring) and adjusting it dynamically.

---

## 🧠 When to Use Sliding Window?

Use this technique when:

* You are dealing with **subarrays / substrings**
* Problem involves **contiguous elements**
* Need to find:

  * Maximum / Minimum length
  * Count of valid subarrays
  * Longest/shortest substring

---

## ⚡ Types of Sliding Window

### 🔹 Fixed Size Window

* Window size is constant (k)
* Example:

  * Maximum Sum Subarray of Size K

---

### 🔹 Variable Size Window

* Window size expands/shrinks based on condition
* Example:

  * Longest Substring Without Repeating Characters
  * Minimum Window Substring

---

## 🧠 Key Insights

* Maintain a **valid window** using two pointers (i, j)
* Expand window → `j++`
* Shrink window → `i++`
* Use:

  * HashMap / Array for frequency
  * Conditions to maintain validity
