# 🌐 Graph Algorithms

This repository contains implementations of important **Graph Algorithms** commonly asked in coding interviews (FAANG level).

---

## 🚀 What is a Graph?

A graph is a data structure consisting of:

* **Nodes (Vertices)**
* **Edges (Connections between nodes)**

Graphs are used to model real-world problems like:

* Social networks
* Maps & navigation
* Dependency systems

---

## 🧠 Core Concepts

* Adjacency List & Matrix
* Directed vs Undirected Graph
* Weighted vs Unweighted Graph
* Cycles & Connectivity

---

## ⚡ Algorithms Covered

### 🔹 Traversal

* Breadth First Search (BFS)
* Depth First Search (DFS)

### 🔹 Cycle Detection

* Undirected Graph (DFS/BFS)
* Directed Graph (DFS / Topological Sort)

### 🔹 Topological Sort

* Kahn’s Algorithm (BFS)
* DFS-based approach

### 🔹 Shortest Path

* Dijkstra’s Algorithm
* Bellman-Ford Algorithm

### 🔹 Minimum Spanning Tree

* Prim’s Algorithm
* Kruskal’s Algorithm (DSU)

### 🔹 Advanced Topics

* Disjoint Set Union (Union-Find)
* Strongly Connected Components (Kosaraju)

---

## 📂 Problems Included

| Problem                   | Algorithm Used   | Time Complexity |
| ------------------------- | ---------------- | --------------- |
| Number of Islands         | DFS/BFS          | O(n × m)        |
| Course Schedule           | Topological Sort | O(V + E)        |
| Detect Cycle (Undirected) | DFS/BFS          | O(V + E)        |
| Dijkstra Shortest Path    | Greedy + PQ      | O(E log V)      |
| Kruskal MST               | DSU + Sorting    | O(E log E)      |

---

## 🧠 Key Insights

* Graph problems often reduce to **traversal (DFS/BFS)**
* Always identify:

  * Cycle?
  * Connected components?
  * Shortest path?
* Use **visited array/set** to avoid infinite loops
