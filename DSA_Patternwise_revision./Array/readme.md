# 📚 Arrays

Arrays are one of the most fundamental data structures and serve as the foundation for many coding interview problems.

This section focuses on mastering array problems through common patterns and techniques.

## 🎯 Patterns Covered

### 🔹 Two Pointers

Use two indices moving towards or away from each other to optimize comparisons and reduce time complexity.

### 🔹 Sliding Window

Maintain a fixed or variable-size window to efficiently process subarrays and substrings.

### 🔹 Prefix Sum

Precompute cumulative sums to answer range queries and subarray problems efficiently.

### 🔹 Kadane's Algorithm

Track the maximum subarray sum ending at each position and update the global optimum.
