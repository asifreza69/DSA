# 🔹 Two Pointers

The Two Pointer technique uses two indices moving towards or away from each other to reduce redundant comparisons and optimize time complexity.

## 🎯 When to Use

* Sorted arrays
* Pair and triplet problems
* Palindrome checking
* Removing duplicates
* Partitioning and merging problems

## 💡 Key Idea

Instead of using nested loops, maintain two pointers and adjust them based on the problem constraints to achieve an efficient solution.

## ⏱️ Complexity

* Time Complexity: Usually **O(n)**
* Space Complexity: **O(1)**

## 🛠️ Language

* C++
