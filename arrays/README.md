# 📊 Array Algorithms

This repository contains solutions to important **Array-based problems** asked in coding interviews (FAANG level).

---

## 🚀 Why Arrays?

Arrays are the most fundamental data structure and form the base of many advanced topics.

Mastering arrays helps you:

* Build strong problem-solving skills
* Understand indexing and memory usage
* Optimize brute force solutions

## 📂 Problems Included

| Problem                | Approach      | Time | Space |
| ---------------------- | ------------- | ---- | ----- |
| Two Sum                | Hashing       | O(n) | O(n)  |
| Maximum Subarray       | Kadane’s      | O(n) | O(1)  |
| Product Except Self    | Prefix/Suffix | O(n) | O(1)  |
| First Missing Positive | Index Mapping | O(n) | O(1)  |
| Majority Element       | Boyer-Moore   | O(n) | O(1)  |

## 🧠 Key Insights

* Arrays focus on **index-based manipulation**
* Optimize using:

  * Prefix sums
  * Hashing
  * In-place techniques
* Many problems reduce from **O(n²) → O(n)**
