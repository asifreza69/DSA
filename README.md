## ⚡ Problem Solving Strategy

1. Identify the pattern
2. Choose optimal data structure
3. Write clean logic
4. Handle edge cases
5. Optimize time & space

---

## ⏱️ Complexity Focus

* Time: O(n), O(log n), O(n log n)
* Space: O(1), O(n)
