# 🔥 Two Pointer Algorithms

This repository contains solutions to popular **Two Pointer problems** asked in coding interviews (FAANG level).

---

## 🚀 What is Two Pointer Technique?

Two Pointer is an efficient approach where we use **two indices** to traverse an array or string.

It helps in:

* Reducing time complexity (O(n²) → O(n))
* Solving problems involving pairs, subarrays, or partitions

---

## 🧠 Common Patterns

### 1. Opposite Direction (Start & End)

* Used in sorted arrays or palindrome problems
* Example:

  * Trapping Rain Water
  * Valid Palindrome

### 2. Same Direction (Fast & Slow Pointer)

* Used for cycle detection or removing duplicates
* Example:

  * Remove Duplicates from Sorted Array

### 3. Sliding Window (Variant)

* Used for subarrays and substring problems
* Example:

  * Longest Substring Without Repeating Characters

## ⚡ Key Insights

* Always process the **smaller/lower constraint side**
* Helps avoid unnecessary nested loops
* Often combined with:

  * Sorting
  * Hashing
  * Sliding Window
